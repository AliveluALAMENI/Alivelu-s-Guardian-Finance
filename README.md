## 🌟 Executive Summary

**GuardianFi AI** transforms digital finance from a low-trust transaction utility into an empowering, AI-guided **Personal CFO**. Developed in response to the "High-Frequency, Low-Trust" paradox observed in modern digital payment ecosystems, GuardianFi AI implements **The Guardian Architecture** — a breakthrough dual-layer framework:

1. **Layer 1: Transparency Layer (The Guardian Ledger & Unified Portfolio):**  
   Consolidates fragmented bank accounts (connected via RBI Account Aggregator framework with selectable bank list), incomes, expenditures, active SIPs, loan EMIs, paper investments, and physical assets into a single real-time "Financial Truth" dashboard, regulated by DPDP Act compliance.
   
2. **Layer 2: Invisible Shield (Behavioral Biometric AI):**  
   Non-intrusively monitors interaction physics — keystroke dynamics, typing intervals, and anomaly patterns — silently protecting users against coerced transfers, UPI phishing, and account takeovers via the **Safe-Guard Checkout Interceptor**.

## 🚀 How to Run GuardianFi AI

GuardianFi AI supports **dual operational modes**:

### Mode 1: Backend Persistence Mode (Recommended for Evaluation & Judges)
Persists all user data, bank linkages, stock trades, and immutable audit logs to local disk files (`data/db.json` & `data/history.json`):
1. Navigate to the project directory:
   ```bash
   cd GuardianFi
   ```
2. Start the zero-dependency Node.js server:
   ```bash
   node server.js
   # Or on Windows, simply double-click start.bat
   ```
3. Open your browser at **`http://localhost:3000`**.
4. The sidebar will display **`🟢 Backend Live (Port 3000)`**. All actions (transactions, debt changes, bank accounts, stock buys/sells) are saved to disk with SHA-256 integrity logs.

### Mode 2: Standalone Offline Mode (Zero Setup)
1. Double-click **`index.html`** directly in any modern browser.
2. The sidebar will indicate **`🟡 Local Cache (Offline)`** and operate with full capabilities using browser `localStorage`.

## 💾 Backend Architecture & Disk Persistence Engine

GuardianFi includes a native, zero-dependency Node.js backend server (`server.js`) located in `GuardianFi/`:
- **`data/db.json`:** Stores active user state (accounts, transactions, debts, goals, investments, portfolio).
- **`data/history.json`:** Immutable append-only historical audit ledger with SHA-256 cryptographic chaining (DPDP Act & RBI Account Aggregator compliance).
- **`data/snapshots/`:** Automated point-in-time state recovery snapshots.

### Available REST Endpoints:
- `GET /api/health` — Server health, uptime, and database metrics
- `GET /api/state` — Fetch current user data state
- `POST /api/state` — Persist updated state to disk & snapshot
- `GET /api/history` — Fetch immutable event log timeline
- `POST /api/history` — Append custom audit event to history
- `POST /api/reset` — Reset database to clean slate or demo state
- `GET /api/export` — Download consolidated JSON backup of state + full audit trail

## ⚡ Chromium Platform & Progressive Web App (PWA) Capabilities

GuardianFi harnesses modern Chromium and Chrome Server Web Platform APIs while maintaining **100% zero external npm dependencies**:

1. **Progressive Web App (PWA) & Service Worker (`sw.js` & `manifest.json`):**
   - **Native Desktop App Installation:** Installable directly from Google Chrome (`⊕ Install GuardianFi` button or address bar prompt). Launches in dedicated standalone window with custom OS branding and zero browser toolbars.
   - **App Shell Caching:** Service worker pre-caches core HTML, CSS, JS, and high-resolution SVG assets for instant launch (<50ms) and resilient offline fallback.
   - **Background Synchronization:** Queues local changes during network drops and syncs with `data/db.json` and `User data base.xlsx` upon reconnection.

2. **On-Device Chrome Built-in AI (`window.ai` / Gemini Nano):**
   - Directly connects to Google Chrome's embedded on-device Large Language Model (Gemini Nano) via the Chrome Prompt API (`window.ai.languageModel`).
   - Executes financial queries on-device using the user's NPU/GPU without transmitting sensitive banking data over the cloud.
   - Automatic graceful fallback to the deterministic mathematical financial rule engine if Gemini Nano is unavailable.

3. **Hardware Biometric Passkeys (WebAuthn / FIDO2 / Windows Hello):**
   - Enables one-touch biometric login using Windows Hello facial/fingerprint sensors or Chrome Passkeys.
   - Bypasses traditional password vulnerability while elevating the user's Behavioral Trust Score to 99%.

4. **Native OS Desktop Push Notifications:**
   - Real-time Chrome OS notifications alert users when their Debt-to-Income (DTI) ratio surpasses safe thresholds (>35%) or when critical financial risk events occur.
